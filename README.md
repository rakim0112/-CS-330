# 3D Music Production Workstation

**C++ · OpenGL · GLSL · 3D Graphics**

An interactive 3D scene representing a music production workstation. The project was developed incrementally from basic geometry into a finished environment with custom scene objects, textures, materials, lighting, and camera controls.

## Project Highlights

- Custom 3D scene construction
- Primitive geometry combined into more complex objects
- Texture mapping
- Material configuration
- Dynamic lighting
- Camera navigation and controls
- Modular OpenGL development
- Incremental testing and visual refinement

## Technical Approach

The scene was developed in stages so individual elements could be tested before being integrated into the final environment. Geometry, textures, lighting, and camera behavior were refined throughout development rather than being implemented as one large feature.

This approach provided hands-on experience with the graphics pipeline and with debugging a program where visual output is an important part of testing.

## What This Project Demonstrates

This project demonstrates experience with low-level graphics programming, 3D scene organization, rendering concepts, visual debugging, and iterative software development. It also shows how a technical project can combine programming with visual design requirements.
