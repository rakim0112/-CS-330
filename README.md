
# CS-330 Comp Graphics and Visualization Portfolio Reflection

## How do I approach designing software?

I approach software design by first identifying the overall goal of the project and then breaking it down into smaller components that can be developed and tested individually. During this project, I focused on planning the scene layout before implementing the individual objects. Creating a clear vision for the final environment helped guide decisions regarding object placement, textures, lighting, and camera positioning.

### What new design skills has your work on the project helped you to craft?

This project strengthened my ability to design 3D environments and think spatially about how objects interact within a scene. I learned how to create visual balance through object placement, lighting, and texture selection. I also gained experience designing scenes that are both functional and visually appealing.

### What design process did you follow for your project work?

I followed an iterative design process. I began with simple primitive shapes and gradually transformed them into more complex objects. As new concepts were introduced throughout the course, I continued refining the scene by adding textures, lighting, camera controls, and additional details.

### How could tactics from your design approach be applied in future work?

Breaking large projects into smaller tasks can be applied to many software development projects. Planning before implementation, creating prototypes, and making gradual improvements are strategies that help reduce complexity and improve project organization.

## How do I approach developing programs?

I approach program development by building a working foundation first and then adding features incrementally. I prefer to test functionality frequently so that issues can be identified and resolved before they affect other parts of the project.

### What new development strategies did you use while working on your 3D scene?

One new strategy I used was modular development. Rather than creating everything at once, I developed individual scene components separately and then integrated them into the larger project. I also learned how to manage textures, materials, lighting, and camera controls within a graphics application.

### How did iteration factor into your development?

Iteration played a significant role throughout the project. Each milestone introduced new concepts that built upon previous work. I continually refined object shapes, improved textures, adjusted lighting, and modified scene composition to improve the final result.

### How has your approach to developing code evolved throughout the milestones, which led you to the project's completion?

As the course progressed, I became more comfortable reading, modifying, and debugging OpenGL code. My confidence increased as I learned how different components worked together. I also became more organized in my coding practices by using comments, modular functions, and incremental testing.
